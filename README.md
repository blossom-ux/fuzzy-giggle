# Распознавание чисел (цифр) — нейросеть

Нейросеть (свёрточная, PyTorch) для распознавания чисел **цифр 0–9** по изображению.

## Как это работает

- **`data.py`** — генератор синтетического датасета: цифры 0–9, 28×28 пикселей, с сдвигом, поворотом, шумом (в стиле MNIST).
- **`model.py`** — архитектура `DigitNet`: 2 свёрточных слоя + 2 полностью связных слоя.
- **`train.py`** — обучение: подсчёт loss, оценка точности на валидации, сохранение лучших весов в `digit_net.pt`.
- **`recognize.py`** — распознавание:
  - `python recognize.py --demo` — демо на сгенерированных цифрах;
  - `python recognize.py файл1.png файл2.png` — распознавание цифр из ваших изображений.

## Установка

```bash
pip install -r requirements.txt
```

## Обучение

```bash
python train.py
```

По окончании обученная модель сохраняется в `digit_net.pt`.

## Использование

```bash
python recognize.py --demo
python recognize.py my_digit.png
```

Входное изображение приводится к 28×28 в оттенках серого. Схема считается тёмной на светлом фоне (при необходимости инвертируется автоматически).

## Требования

Python 3.8+, PyTorch, numpy, matplotlib, Pillow (см. `requirements.txt`).
